Materi day 1 membahas dua hal utama, yaitu Prompt Engineering menggunakan AI dan penggunaan Git/GitHub untuk mengelola proyek serta bekerja secara kolaboratif.

1.Prompt Engineering
Prompt Engineering adalah cara menyusun instruksi atau perintah kepada AI agar menghasilkan jawaban yang tepat, relevan, dan sesuai kebutuhan.
Prompt merupakan masukan yang diberikan kepada AI Bentuknya bisa berupa pertanyaan sederhana, kata kunci, instruksi panjang, hingga potongan kode.

Ada 4 bagian penting dalam membuat prompt:
- Role : Menentukan peran AI. Contohnya, meminta AI bertindak sebagai seorang web developer.
- Task : Menjelaskan tugas yang harus dikerjakan AI.
- Context : Memberikan informasi tambahan agar AI memahami kebutuhan kita.
- Format : Menentukan bentuk hasil yang diinginkan, misalnya berupa kode, tabel, atau penjelasan.

2.Git
Git adalah sebuah Version Control System (VCS) yang digunakan untuk mencatat dan mengelola perubahan pada file atau kode program.
Ada tiga bagian utama dalam proses kerja Git:
- Working Directory: Tempat kita mengerjakan dan mengubah file proyek.
- Staging Area: Tempat menampung perubahan yang akan disimpan ke dalam commit.
- Git Directory (Repository): Tempat Git menyimpan data, riwayat perubahan, dan informasi proyek.

Perbedaan Git dan GitHub : Git adalah alat untuk mengelola perubahan kode, sedangkan GitHub adalah tempat untuk menyimpan repository Git secara online dan berkolaborasi dengan orang lain.

beberapa perintah dasar Git :
git init : Membuat repository Git baru
git add . : Memasukkan perubahan ke staging area
git add --all : Menambahkan semua perubahan ke staging area
git commit -m "pesan" : Menyimpan perubahan ke repository
